# myBook

读书笔记仓库：一本书内容很多，不需要全记，只记你指出的那一点。
碎片攒下来，需要的时候再取出来看，或者生成语音在路上听。

## 文件一览

- `notes.md`：读书碎片笔记，按书名分类，是平时记笔记、取笔记的唯一入口。
- `行动瑜伽.txt`：《行动瑜伽》全文的可听版。2026-11-01 已清理 PDF 转换产生的杂项：删掉单独成行的“一”到“七”共 20 处、目录标题尾部挂着的“一”、重复的附录标题，并压缩了多余空行；正文顺序和内容未动。
- `pinga-fogo-chico-xavier-总结.md`、`不反應.pdf`、`不思考.pdf`、`斷念.epub`：仓库里已有的书和资料。

## 怎么记笔记

把碎片发给助手就行，文字、书页拍照、语音都可以，只记你指出的那一点，
不用你自己整理格式。发的时候最好顺带说一句是哪本书、你对这一点的感想。

助手收到后会直接追加到 `notes.md` 并提交到 `main` 分支，不走 PR 流程。

## notes.md 的格式

一本书一个顶级标题，同书的新碎片追加在该书那一节里：

```markdown
# 书名

### 2026-11-01

原文摘录：……

你的一句感想：……
```

每条碎片固定包含日期、摘录、感想，方便以后按书名、时间检索。

## 怎么取出来

- 按书名、标签或时间查：助手从 `notes.md` 里找出对应内容，直接贴给你看。
- 路上听：助手把取出的内容生成语音，可以拼成一段通勤可听的长度。
- 随机讲一本：你说“随机讲一本”，助手就按下面的轮次规则选一本讲给你听。

## 随机讲一本的规则

不用每次独立随机抽，那样会连抽同一本、有的本长期抽不到。

- 把 `notes.md` 里的全部书洗牌成一轮队列，每次取队列里的下一本。
- 一轮里每本书恰好讲一次，轮空了再全部重新洗牌。
- 新书进来时随机插进当前这一轮，不会为了追平旧账连讲好几遍。
- 点名要某本书不算随机，不消耗轮次。
- 讲述次数、轮次记录在助手那边，不写进 `notes.md`，笔记本身保持干净可读。

一次默认讲那本书里的一条碎片；想一次听整本书的笔记，跟助手说一声即可。

## 注意

不要直接把凭证贴在聊天里或写进文件里。
